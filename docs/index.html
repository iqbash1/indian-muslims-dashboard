Indian Muslims — Living Conditions Dashboard

Built 2026-05-29 07:58 · source on GitHub

A scorecard of living-conditions indicators for India's Muslim population, with Hindu and all-India comparison baselines on every metric. The gap between Muslim outcomes and these baselines is the story this dashboard is built around — inheriting the Sachar Committee (2006) methodology of focused, comparative measurement.

Each tile shows: source path, methodology note, "data current to" badge, and a link to the underlying canonical CSV. Click any column header in the scorecard to sort. Numbers tagged "paradox" are ones where Muslim outcomes run ahead of Hindu — notably infant survival, women's anaemia, and sex ratio. These coexist with persistent Muslim disadvantage on the socioeconomic, representation, and justice indicators.
