About this measurement

Definition. Total number of students classified as "Muslim Minority" enrolled in higher education institutions, per AISHE annual reporting.

Methodology. AISHE classifies enrolment as "Muslim Minority" vs "Other Minority Community" (Christians, Sikhs, Buddhists, Jains, Parsis), with Hindu enrolment implied as residual. This metric publishes only the absolute Muslim enrolment. Muslim *share* of total enrolment is a separate metric that requires Total Enrolment by state (separate AISHE table not yet extracted).

Sources. AISHE 2021-22. Data file: muslim-higher-ed-enrolment.csv.
