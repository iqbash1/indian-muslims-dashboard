## Critical methodological gap: no religion crosstabs in published tables

**HCES 2022-23 does not publish MPCE by religion in either the factsheet or the full Report 591.** Religion of the head of household is collected as survey variable Q4.11, but the published tables aggregate by sector, state, social group and fractile only - so the mid-point needs unit-level data.

**BLOCKED at the unit-level step (verified 2026-06-11):** the NADA catalog
(id 224, idno DDI-IND-MOSPI-NSSO-HCES22-23) distributes the unit data ONLY
as a 117 MB zip containing a single 2.5 GB proprietary `.Nesstar` binary
(banked: zip local at ~/Desktop/nada-work/hces-2022-23/, sha256 + docs in
sources/nada/hces-2022-23/, incl. the fixed-width Layout xlsx + the
Readme - which describe a 15-file `hces22_lvl_01..15.txt` distribution
that exists NOWHERE public). No mospi.gov.in TXT mirror exists: the
2022-23 release (June 2024) post-dates the Drupal file store, so the
NSS7718-style unlinked-directory trick has nothing to find; data.gov.in
has nothing; esankhyiki returns fake-200 SPA shells. Unlock = Nesstar
Explorer export in a Windows VM (the same session would also unlock AIDIS
2003, CES 2009-12 and health/education 2014).

**Status of the `mpce` canonical metric:** LIVE since Commit EV/EO (hero +
By-state from HCES 2023-24 unit-level CSV, which NADA does ship openly;
2004 point from Sachar). This 2022-23 round would only add a mid-point
between them.

## What CAN be extracted from the published tables

- National + state MPCE (all-religion combined) — from factsheet
- State-wise MPCE breakdowns
- MPCE by social group (SC/ST/OBC/Other)
- Food share of expenditure
- Expenditure by quintile

These are dashboard-usable as background context but not Muslim-disaggregated.

## Relation to HCES 2023-24

The 2023-24 round is a separate live source (`hces-2023-24`): its NADA

By-state tab) and top-quintile-share. See docs/runbooks/hces-microdata

## Known issues

- The 2011-12 round and 2022-23 round used different questionnaires; not directly comparable. NSS officially treats them as a methodology break.
- Unit-level processing is the only path to religion crosstabs; no published table fills this gap.
- HCES 2023-24 may follow the same pattern (no published religion crosstabs).
