# Runbook: HCES 2023-24 unit-level microdata

## Source identity

- Manifest entry: `hces-2023-24` (manifest/sources.yaml)
- Survey: Household Consumption Expenditure Survey 2023-24, NSO / MoSPI (NSS
  Report no. 592). Field period Aug 2023 to Jul 2024; 2,61,953 households.
- Catalog: id 237 / idno `DDI-IND-MOSPI-NSS-HCES23-24` on microdata.gov.in.
- Feeds: the **`mpce`** metric's current (2023-24) religion-wise figure.

## What we publish from it

Monthly per capita consumption expenditure (MPCE) by religion of the household
head, all-India and urban/rural: Muslim Rs 4,454 (rural 3,874 / urban 5,467),
Hindu Rs 4,974, all-India Rs 4,958. Computed from the microdata, NOT a published
table (MoSPI's factsheets break MPCE down by social group only, never religion).

## How to refresh (MoSPI NADA API)

Catalog browsing is open; **file download needs a personal API key** generated in
a microdata.gov.in (NADA) account, sent as the `X-API-KEY` header. Gotchas: the
fileslist/download endpoints take the **idno string** (numeric id 237 returns
`IDNO-NOT-FOUND`); `{FileNo}` is the base64 of the filename from `fileslist`.

```bash
KEY=<your personal NADA API key>
ID=DDI-IND-MOSPI-NSS-HCES23-24
curl -H "X-API-KEY: $KEY" "https://microdata.gov.in/NADA/index.php/api/datasets/$ID/fileslist"
curl -H "X-API-KEY: $KEY" -OJ \
  "https://microdata.gov.in/NADA/index.php/api/fileslist/download/$ID/SENFU19EYXRhXzIwMjMtMjRfQ3N2LnppcA=="
```

The CSV data zip (`HCES_Data_2023-24_Csv.zip`, 244 MB, 15 level CSVs) is **kept
local, not committed** (provenance-only archival; sha256 in
`sources/hces-2023-24/HCES_Data_2023-24_Csv.zip.meta.json`). See
`sources/hces-2023-24/PROVENANCE.md` for the full re-fetch + verify steps.

## How to recompute

```bash
python transform/hces/extract_mpce_2023_24_by_religion.py path/to/HCES_Data_2023-24_Csv.zip
```

The script encodes the validated method (NSS estimation procedure section 3.5;
`Total_Consumption_Value` from the detail levels L05-L13, 365-day items / 12,
weighted by the multiplier, religion from L03). It prints the national validation
(reproduces published rural Rs 4,122 / urban Rs 6,996 within ~2%) and the religion
split. Then update the `year=2023` rows in `canonical/mpce.csv`.

## Caveats (NSO unit-data rider)

Religion is self-reported and unverified; the survey is designed to estimate MPCE
with the State/UT as the basic stratum. MPCE cross-classified *by* religion is the
intended use; estimating population composition from these fields is not, and **no
sub-state (district) estimates** are permitted. The card states these caveats. The
two consumption methods differ (2004-05 URP vs 2023-24 MMRP) and rupees are
nominal, so the comparable story across the Sachar 2004-05 benchmark and now is the
relative gap (Muslims ~10% below the national average, stable, widest in towns),
not the rupee level.
